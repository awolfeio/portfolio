Replica is a powerful Figma plugin designed to generate DESIGN.md files based off Design System Figma Variables. This streamlines the capability for a developer to build design system foundations and UI that more accurately matches Figma files right out the gate.

When Google open-sourced their DESIGN.md spec, I figured it made sense to allow Figma to rapidly bridge design system variables to this format that is best for LLM-assisted development.
